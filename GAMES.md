# Independent Games (separate from Chain Loot GameFi)

These three titles are **standalone games** — not part of Chain Loot play-to-earn.

| Folder | Game | Platform |
|--------|------|----------|
| `realm-conquest-browser/` | **Realm Conquest** — medieval hex strategy | Browser (`npm run web` → :8080) |
| `neon-drift-pc/` | **Neon Drift** — cyberpunk arcade shooter | PC / Pygame (`npm run pc`) |
| `shadow-strike-mobile/` | **Shadow Strike** — underrealm brawler | Mobile / Expo (`npm run phone:web` → :8082) |
