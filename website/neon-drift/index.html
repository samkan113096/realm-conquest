What’s in the run

100 warp gates

Escalating waves, combos, and power-ups. Boss Dreadnought every 5 gates.

Campaign save

Pause anytime — progress auto-saves. Continue from the main menu.

Standalone PC game

Not a browser title and not GameFi. Install Pygame and run locally.

Play on your machine

cd neon-drift-pc
pip3 install -r requirements.txt
python3 main.py

# or from the game repo root
npm run pc
