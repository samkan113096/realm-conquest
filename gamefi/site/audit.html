Upgradeability (Zombie Siege)

Zombie Siege deploys behind an ERC-1967 UUPS proxy so gameplay and reward logic can be improved without migrating player NFTs or LOOT balances.

  • UPGRADER_ROLE required for implementation upgrades via upgradeToAndCall
  • initialize() replaces constructor; implementation disables initializers
  • 39-slot storage gap reserved for future variables
  • Custom nonReentrant modifier (upgrade-safe; no constructor-based guards)
  • Future upgrades: npm run upgrade:siege on admin network

Play-to-Earn (On-Chain)

Defeating a zombie with a hero NFT mints LOOT to the player wallet on victory. Rewards scale by tier and hero rarity (Epic +20%, Legendary +50%). Higher combat power unlocks harder tiers with larger payouts — incentivizing better hero and weapon mints.
